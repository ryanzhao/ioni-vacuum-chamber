## Parameter register

For each new parameter record: ID, quantity, value, unit, type (target/design input/configuration/prediction/measurement), applicable condition, source location, owner, reviewer, status and revision. Use UNKNOWN rather than a guessed number.

## Interface register

Record each port, mount, electrical channel, gas line and data interface with an ID, two responsible workstreams, connector/flange specification, proposed vs accepted status, CAD/manual reference and review date. Interface changes require both sides to review before release.
