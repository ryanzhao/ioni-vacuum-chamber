# Papers, video and website evidence

Keep raw photos, video and large recordings in managed storage. Commit manifests, captions/scripts and reviewable lightweight derivatives here when authorized. The setup does not upload the existing media library or publish a site/video.

For a paper, preserve source bibliography, contribution log, reproducible analysis, raw-run links and a figure-to-evidence index. For each figure record its input run IDs, script/commit, parameters and uncertainty.

For YouTube or the website, use a media record to connect the technical claim, source footage, edit, consent/rights, credits and final release. Public release needs a reviewed final artifact. Keep draft, approved, uploaded and live-verified states distinct.

Existing teaching content should retain its original scientific limitations and authorship metadata. Review the applicable current source edition before reuse; do not assume an old local filename is the latest edition.
